# 1. INTRODUCTION
This laboratory manual is designed in accordance with the **CSIT-302 Data Structures & Algorithms Lab syllabus** under the AICTE Flexible Curricula for III Semester.

The experiments follow a structured progression — from basic array operations, dynamic inputs, modular function designs, and class-based object configurations, to advanced concepts such as stack/queue operations, singly linked lists, search/sort algorithms, and pointer manipulations.

Each experiment uses **C++** with the standard GCC / G++ compiler or any compatible C++ IDE.

---

# 2. COURSE OBJECTIVES
- To understand and execute basic operations on **one-dimensional arrays**
- To dynamically load, manipulate, and replace elements in **contiguous structures**
- To practice passing arrays to **functions** and implementing **modular designs**
- To apply Object-Oriented Programming (OOP) concepts via **classes and objects**
- To implement and analyze **linear data structures**: Stack and Queue using arrays
- To create and traverse a **Singly Linked List** and perform insertion and deletion
- To perform advanced operations on linked lists including **reversal, sorting, and aggregate math**
- To design, implement, and analyze sorting algorithms like **Bubble Sort**
- To implement and evaluate efficient search techniques like **Binary Search**
- To manipulate characters and strings using **pointers and pointer arithmetic**

---

# 3. SOFTWARE REQUIREMENTS
- **Compiler**: GCC / G++ compiler (v11.x or higher recommended)
  > [minGW](https://sourceforge.net/projects/winlibs-mingw/files/) compile at C:/mingw64
- **IDE / Editor**: Visual Studio Code / Code::Blocks / Dev-C++
- **Debugger**: GDB (GNU Debugger)
- **OS**: Windows 10 / 11 or Linux (Ubuntu/Fedora/Debian)

# 5. GENERAL INSTRUCTIONS
- Each experiment follows the standard format:
  - **Aim** — Precise objective of the program
  - **Theory** — Core data structure concepts and logic explained simply
  - **Implementation Code** — Source code in C++
  - **Expected Output** — The console output representing successful run
  - **Viva / Discussion Questions** — Key theoretical and conceptual inquiries
- All C++ files are located within their respective experiment folders and can be compiled using standard compilers.
- VS Code setup is configured through the `.vscode` task environment to build the active file.
- Students must document and trace the algorithm executions in their lab record.
